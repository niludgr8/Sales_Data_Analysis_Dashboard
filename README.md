# Sales_Data_Analysis_Dashboard
An Excel sales dashboard project featuring interactive KPI summaries and sales analysis by region, country, product, and sales channel. Includes a dataset of 2,707 sales records with revenue, cost, gross profit, and margin metrics. The workbook contains a dashboard, pivot table summaries, and the underlying sales data.
# Sales Data Analysis Dashboard

An Excel dashboard project for exploring sales performance across regions, countries, products, and sales channels.

## Workbook contents

- **Dashboard** — visual overview of sales performance
- **Pivot Table** — summarized sales metrics
- **SalesDataTable** — source data with 2,707 sales records

## Metrics

The workbook includes revenue, cost of goods sold (COGS), gross profit, gross margin, and units sold.

## Tools

- Microsoft Excel
- Pivot tables and charts

## Getting started

Download or clone this repository, then open `Sales_Data_Excel.xlsx` in Microsoft Excel to view the dashboard and explore the data.

## Data fields

The sales data includes order date, region, country, sales channel, customer type, product category, product, units sold, unit price, discount, unit cost, revenue, COGS, gross profit, and gross margin.

## Project purpose

This project demonstrates how Excel can be used to organize sales data and present key business metrics in a dashboard.
